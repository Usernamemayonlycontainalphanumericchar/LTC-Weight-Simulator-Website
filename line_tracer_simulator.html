PENGGUNAAN SIMULASI
Simulasi ini diperuntukkan untuk Robot Line Tracer menggunakan sistem berat pada pemrosesan sensornya

\(error = \frac{\sum_{n}^{a}(sensor(n)(weight(n)))}{\sum_{n}^{a}sensor(n)}\)

\(Number of Sensor\) mengatur banyaknya sensor yang digunakan

\(Distance Between Sensor\) mengatur jarak antar sensor

\(sensor size\) mengatur bukaan sensor

\(line width\) mengatur lebar garis lintasan

\(line gradient distance\) mengatur ukuran gradien pada tepi garis

Untuk simulasi pembacaan garis pada sensor menggunakan

\(S_i=\frac{1}{N}\sum_{x=x_{i}^{-}}^{x_{i}^{+}}f(x)\)

dimana

\(f(x)=\left\{\begin{matrix}\left\lfloor \mathcal{U}(0,100)\right\rfloor & \text{if } x_{neg} < x < x_{pos} \\ 4096 & \text{otherwise}\end{matrix}\right.\)

Menentukan Modulasi pada tiap motor menggunakan

\(PWM_{modulation(n)} = \frac{Speed_{n}}{Speed_{max}}(PWM_{max})\)
